Connect to GitHub

Your site lives on GitHub, so this page saves your changes there. Connect once on each phone or computer you use.

How to get a token (one time):
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Tap Generate new token. Name it Site admin and pick an expiry (up to 1 year).
  3. Under Repository access, choose Only select repositories and pick your site repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it and paste it above.
